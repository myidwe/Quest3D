첫 연결

PC와 Quest를 같은 공유기의 로컬 네트워크에 연결합니다. PC를 시작한 뒤 Quest의 Scan으로 PC를 선택하고 Pair를 누릅니다. PC가 검색되지 않으면 Select Server → +에서 PC 앱 하단에 표시된 주소를 입력하세요.

Quest에 표시된 네 자리 PIN을 PC 앱의 Connection → 새 Quest 연결에 입력하고 연결 승인을 누릅니다. 승인 후 Quest에서 PC에 연결합니다.

화면 조절

AI Quality · 분석 품질

PC의 Settings → Quality → AI Quality에서 Standard 또는 Quality · Preview를 선택합니다. PC 중지 → 선택 → PC 시작 → Quest Connect 순서로 적용하세요.

Standard는 처리 속도를 우선하고, Quality는 PC 영상의 깊이를 더 세밀하게 분석합니다. Quality에서는 처리 속도가 낮아지고 장면에 따라 윤곽과 입체감이 달라집니다. 같은 장면과 같은 Depth 값으로 비교하세요. 전송 해상도와 Quest 설정창 크기는 바뀌지 않습니다. 새 모델을 받거나 APK를 다시 설치할 필요도 없습니다.

Depth model · 모델 비교

PC의 Settings → Quality → Depth model에서 DAv2 Small (기본) 또는 DAD Small (비교)를 선택합니다. 설치된 모델은 영상 전송 중에도 재연결 없이 바꿀 수 있습니다.

같은 장면과 Depth 값으로 비교하세요. DAD는 일부 장면에서 윤곽이 더 편안하게 보이지만 입체감이 줄어들 수도 있습니다. 같은 메뉴에서 기본 모델로 돌아갈 수 있습니다. PC가 중지된 상태에서 선택하면 다음에 PC를 시작할 때 적용됩니다. 설치하지 않은 모델은 선택할 수 없습니다.

Quest view

PC 앱의 Display → Quest view → 화면 설정에서 각 설정을 어디에서 조절하는지 확인할 수 있습니다. 가상 화면을 배치하는 조작은 Quest 설정창에서 합니다. PC에서는 원본 화면, 입체 변환과 전송 품질을 설정하고, Quest에서는 가상 화면의 배치와 감상 환경을 설정합니다.

Quest 설정창은 세로로 구성되어 있습니다. Display의 Size·Center·Lock 아래에서 Position / Views / Environment / Framing을 선택하세요. 상세 설정에서 돌아가려면 왼쪽 위 화살표를 누릅니다.

Size · 화면 크기

Quest의 Display → Size에서 슬라이더나 −/+ 버튼으로 조절합니다. −/+ 버튼은 5%씩 조절하며, 길게 누르면 계속 바뀝니다. 현재 가상 화면의 너비와 거리는 같은 행에 표시됩니다. 영상 해상도와 Depth 값은 바뀌지 않습니다.

Position · 거리·수평·회전

Alignment → Level이 기본값입니다. Center를 누르거나 화면을 옮기거나 손잡이를 조절해도 수평을 유지합니다. Center를 누르면 크기와 거리를 유지하면서 화면을 눈높이의 정면으로 옮깁니다. 화면을 기울이려면 Free를 선택하고 Tilt(앞뒤)·Roll(좌우)을 2°씩 조절하세요. Free에서 Center를 누르면 현재 시선 각도를 따릅니다. 수평 맞추기를 누르면 Level로 돌아갑니다.

Distance는 가상 화면까지의 거리입니다. 기본 설정에서는 화면 너비가 유지되므로 멀수록 작게 보입니다. 보이는 크기 유지를 켜면 거리와 너비를 함께 바꿔 눈에 보이는 크기를 유지합니다. 조절 가능한 거리 범위는 곡률과 너비에 따라 표시됩니다. ± 버튼은 25cm씩, 위치 화살표는 10cm씩 조절합니다. 헤드셋 렌즈의 물리적 초점거리는 바뀌지 않습니다. Lock을 켜면 영상 배치가 잠기지만 설정창은 계속 조작할 수 있습니다.

Views · 보기 저장

Standard: 너비 2.4m·거리 2.5m·평면·Level
Cinema: 너비 4m·거리 3m·Gentle·Level
Reclined: 현재 시선 각도에 맞춰 한 번 배치·Free
Save view / My view: PC별로 현재 배치와 정렬 방식 저장·불러오기

Level로 저장한 보기는 현재 머리 위치와 수평 방향을 기준으로 불러옵니다. Free로 저장한 보기는 시선의 기울기도 반영합니다. 크기, 배치, 곡률과 잠금 상태를 저장하며 모델, Depth, 색감과 전송 설정은 바꾸지 않습니다. 잠긴 화면을 조절하려면 Display에서 Lock을 해제하세요.

Environment · 곡률·배경

Flat / Gentle / Curved에서 화면 형태를 선택합니다. Bezel, Passthrough, Background, Ambient와 조명 색도 이 화면에서 조절할 수 있습니다.

Framing · 여백 자르기

PC 영상에 연결한 뒤 Top / Bottom으로 위·아래의 검은 여백을 각각 0–25%까지 자를 수 있습니다. 좌우 눈에 같은 비율을 적용하고 화면비는 유지합니다. Fit · 원본 복원을 누르면 바로 되돌아갑니다.

영상 안의 자막도 함께 잘리므로 확인하세요. 여백을 자르는 동안에는 테두리가 잠시 숨겨지고, 원본을 복원하면 기존 Bezel 설정으로 돌아갑니다. 여백을 자동으로 감지하거나 가려진 영상을 복원하거나 화질을 높이는 기능은 아닙니다.

Menu / Pointer · 설정창과 포인터

Quest의 Connect → Menu / Pointer에서 조절합니다. Menu → 크기를 누르면 85%·100%·120% 순서로 바뀌고, Center를 누르면 설정창이 정면으로 이동합니다. 메뉴 크기는 PC 영상 크기와 별개입니다. 설정창은 하단 손잡이로 옮길 수 있습니다. Alignment는 영상과 설정창에 함께 적용됩니다. 기본값인 Level에서는 메뉴도 수평을 유지하며, Free에서는 시선 각도를 반영합니다.

Pointer에서는 메뉴 포인터 크기를 100%·120%·150%로 선택하고 Normal/High 대비, 포인터 모양과 떨림 보정을 설정할 수 있습니다. Input에서는 손 추적과 주로 사용하는 손을 선택합니다. 현재 버전에서는 Quest로 PC 마우스, 키보드와 게임패드를 원격 조작할 수 없습니다.

Quality · 선명도·색감·전송

Sharpness에서는 선명도와 샘플링을, Color에서는 밝기, 명암과 Gamma를 조절합니다. Tint는 Temperature 값 아래의 차갑게/따뜻하게 버튼과 Tint 값 아래의 초록빛/자홍빛 버튼으로 조절합니다. Reset · 색조 복원은 색온도와 색조만 중립 값으로 되돌립니다.

Stream에서는 해상도, FPS, Bitrate, Codec과 실제로 수신한 영상의 Eye 정보를 확인합니다. 연결 전에는 수신 대기 상태로 표시됩니다.

Sound · 소리 출력

PC 중지 → Settings → Sound → 출력 선택 → PC 시작 → Quest Connect

Quest only연결 중에는 Quest에서만 재생 · 연결이 끝나면 PC 출력으로 복원

Quest 음량은 헤드셋 볼륨 버튼으로 조절합니다. Quest only를 사용하려면 Steam Streaming Speakers가 활성화되어 있어야 합니다. 사용할 수 없으면 이유가 표시됩니다. PC + Quest는 두 기기의 재생 시점이 달라 소리가 겹칠 수 있습니다.

특정 앱의 소리만 PC에 남는 경우

Windows 음량 믹서에서 해당 앱의 출력 장치를 기본값으로 바꾸고 재생을 다시 시작하세요. Sterevi는 각 앱에 따로 지정된 출력 장치를 강제로 바꾸지 않습니다. 연결이 끝난 뒤 PC 소리가 돌아오지 않으면 PC 중지를 누르고 상태를 확인한 뒤 진단을 저장하세요.

숨기기 · 종료

Settings → 트레이로 보내기를 누르면 PC 창만 숨겨지고 영상 전송은 계속됩니다. 바로가기나 트레이 메뉴에서 다시 열 수 있습니다. PC 중지를 누르면 영상 처리와 전송이 종료됩니다.

영상 전송 중 창을 닫을 때 선택: 트레이 / 중지 후 종료 / 취소

문제 해결

PC 검색 · PIN

PC가 검색되지 않으면 PC 앱에 표시된 주소를 Quest에 직접 입력하세요. PIN이 맞지 않으면 Quest 한 대에서 새 연결 요청을 만들고 새 PIN을 사용하세요. 처음 설치한 뒤 통신이 막힌다면 두 기기가 같은 로컬 네트워크에 연결되어 있는지 확인하고 설치창의 연결 허용을 누릅니다.

브라우저의 검은 영상

PC에서는 정상인데 Quest에서만 검게 보인다면 캡처 제한이나 GPU 호환성이 원인일 수 있습니다. 개발 환경에서는 브라우저 하드웨어 가속을 끈 뒤 정상 표시를 확인했습니다. 모든 서비스와 콘텐츠의 재생을 보장하지는 않습니다.

설정 보존 · 진단

PC 설정은 config/desktop.json에, Quest 설정은 헤드셋 앱에 저장됩니다. 업데이트할 때 앱 데이터를 지우지 마세요. 오류 기록은 PC 앱의 Settings → 진단 내보내기에서 저장할 수 있습니다. 개인 페어링 인증서는 다른 PC에 복사하지 마세요.
