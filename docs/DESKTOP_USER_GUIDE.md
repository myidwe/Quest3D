# Sterevi 사용 방법

처음 사용한다면 [처음 설치와 연결](GETTING_STARTED.md)을 먼저 확인하세요. 설치와 개발에 관한 다른 문서는 [문서 목차](README.md)에 모았습니다.

## 매번 사용하는 순서

1. 바탕화면이나 시작 메뉴의 **Sterevi Desktop**을 엽니다.
2. **PC 시작**을 누르고 영상이 준비될 때까지 기다립니다.
3. Quest 앱에서 이 PC의 **Connect**를 누릅니다.

처음 연결할 때는 Quest에서 **Select Server → Scan Network → 검색된 PC 선택 → Pair**를 누릅니다. 헤드셋에 표시된 네 자리 PIN을 PC 앱의 **Connection → 새 Quest 연결**에 입력하고 승인하세요. PC가 시작된 상태에서만 승인할 수 있습니다. 승인 후 Quest에서 연결 상태를 확인하고, 자동으로 연결되지 않으면 **Connect**를 누릅니다. 연결 정보는 다음에 앱을 실행할 때도 유지됩니다. PC가 검색되지 않으면 **+** 버튼을 눌러 PC 주소를 입력하세요.

## Quest 2 / Quest 3 선택

1. 송출 중이면 **PC 중지**를 누릅니다.
2. PC 앱의 **Settings → Quality → Headset**에서 **Quest 2** 또는 **Quest 3**를 선택합니다.
3. **PC 시작** 후 Quest에서 **Connect**를 누릅니다.

PC 영상은 Quest 2에 눈별 1920×1080, Quest 3에 눈별 2048×1152로 전송됩니다. 화면비는 모두 16:9이며, Headset을 바꿔도 Depth와 윤곽 안정화 설정은 유지됩니다. 기존 PC 설정의 기본값은 Quest 2입니다. 높은 해상도에서 영상이 끊기거나 Quest 2를 다시 사용할 때는 위 순서대로 Quest 2를 선택하세요. 모니터도 **PC 중지**를 누른 뒤 변경할 수 있습니다.

Quest 3에는 좌우 영상을 나란히 합친 **4096×1152 Full SBS** 영상을 **HEVC**로 전송합니다. Quest의 **Quality**에서 코덱을 확인할 수 있습니다. 4096×1152는 전송되는 전체 영상의 크기이고, 각 눈이 보는 영상의 화면비는 16:9입니다. 헤드셋 패널의 해상도나 설정창 크기를 뜻하지 않습니다.

새 Quest 3를 사용할 때는 앱을 설치하고 그 헤드셋에서 PC와 처음 페어링해야 합니다. 기존 Quest 2의 인증 파일은 복사하지 마세요. **PC 시작 → Quest의 Select Server → Scan Network → 검색된 PC 선택 → Pair → PC의 Connection에서 새 PIN 승인** 순서로 진행합니다. 승인될 때까지 Quest의 PIN 화면을 열어 두고, 자동으로 연결되지 않으면 **Connect**를 누릅니다. USB는 설치와 진단에만 사용합니다. 영상을 보려면 PC와 Quest가 같은 공유기의 로컬 네트워크에 연결되어 있어야 합니다.

## Sound · 소리 출력

**PC 중지 → Settings → Sound → 출력 선택 → PC 시작 → Quest Connect**

| 출력 | 동작 |
|---|---|
| PC · 기본 | 기존 PC 스피커나 헤드폰에서 재생 |
| Quest only | 연결 중에는 Quest에서만 재생, 연결이 끝나면 PC 출력으로 복원 |
| PC + Quest | PC와 Quest에서 함께 재생 |

Quest의 음량은 헤드셋 볼륨 버튼으로 조절합니다. Quest only를 사용하려면 PC에 Steam Streaming Speakers가 설치되어 있어야 합니다. 사용할 수 없는 PC에서는 해당 옵션이 비활성화되고 이유가 표시됩니다. PC와 Quest에서 함께 재생하면 소리가 겹칠 수 있습니다.

Quest only를 선택해도 특정 앱의 소리가 PC에서 나온다면 Windows 음량 믹서에서 그 앱의 출력 장치를 **기본값**으로 바꾸고 재생을 다시 시작하세요. Sterevi는 각 앱에 따로 지정된 출력 장치를 강제로 바꾸지 않습니다. 연결이 끝난 뒤 PC 소리가 돌아오지 않으면 **PC 중지**를 누르고 상태를 확인한 뒤 진단을 저장하세요.

## 화질 조절

**Settings → Quality → AI Quality**에서 **Standard** 또는 **Quality · Preview**를 선택합니다. **PC 중지**를 누른 뒤 설정을 바꾸고 PC를 다시 시작하세요. Standard는 처리 속도를 우선하고, Quality는 더 높은 해상도로 깊이를 분석합니다. 눈별 전송 해상도는 바뀌지 않습니다. Quality가 모든 장면에서 더 나은 결과를 내거나 일정한 FPS를 보장하지는 않습니다.

**Settings → Quality → Depth model**에서 기본 모델인 **DAv2 Small**과 비교용 **DAD Small**을 선택할 수 있습니다. 설치된 모델은 영상을 전송하는 중에도 재연결 없이 바꿀 수 있습니다. 같은 장면과 Depth 값으로 비교해 윤곽과 입체감이 더 자연스러운 모델을 선택하세요. DAD는 장면에 따라 입체감이 줄어들 수 있습니다. PC가 중지된 상태에서 선택하면 다음에 PC를 시작할 때 적용됩니다. 설치하지 않은 모델은 선택할 수 없습니다.

| 조절 | 의미 |
|---|---|
| Mode · 2D / 3D | 원본 2D 화면과 입체 화면 전환 |
| Depth | 입체감 조절. −/+ 버튼으로 0.05%p씩 조절하며, PC에서는 숫자 입력 후 Enter 또는 슬라이더로 조절 가능 |
| 윤곽 안정화 | 물체 경계에서 좌우 눈에 보이는 영상의 과한 차이를 줄이는 보정. 입체감이 조금 약해질 수 있음 |
| 모니터 | PC를 중지한 뒤 전송할 화면 선택. 현재는 16:9만 지원 |
| Settings · Quality · Headset | PC를 중지한 뒤 Quest 2 / Quest 3 전송 해상도 선택. PC를 다시 시작하고 Quest를 다시 연결하면 적용 |
| Settings · 진단 | 눈별 해상도와 처리 상태 확인. 영상 게시 빈도와 새 AI 영상의 FPS는 다른 수치 |

3D에서 윤곽이 겹쳐 보인다면 Depth를 조금 낮춰 보세요.

Quest의 **Display**에서는 2D/3D, Depth, 화면 크기와 거리를 조절합니다. **3D**에서는 입체 세부 설정을, **Quality**에서는 영상 전송과 선명도, 색감을 조절합니다. 메뉴 하단의 **메뉴 이동** 손잡이를 트리거로 잡으면 설정창을 옮길 수 있습니다. 설정창은 다크 모드가 기본이며 영상 색감에는 영향을 주지 않습니다. 기존 HEVC, 해상도, 색감, 화면 위치 설정도 유지됩니다.

Display의 상세 설정에서는 위치, 곡률, 여백을 조절하고 현재 화면 설정을 저장할 수 있습니다. **Alignment · Level**이 기본값으로, **Center**를 누르거나 화면을 옮겨도 수평을 유지합니다. 누워서 보거나 화면을 기울이고 싶을 때는 **Free**를 선택하세요. 영상 크기, 메뉴 배율, 포인터 크기는 각각 조절할 수 있습니다.

**Position → Distance**는 가상 화면까지의 거리입니다. **보이는 크기 유지 · Off**에서는 화면이 멀어질수록 작게 보입니다. **On**에서는 거리와 너비를 함께 바꿔 눈에 보이는 크기를 유지합니다. 조절 가능한 거리 범위는 곡률과 화면 너비에 따라 표시됩니다. 거리 ± 버튼은 25 cm씩, 위치 화살표는 10 cm씩 이동합니다. 이 설정으로 헤드셋 렌즈의 물리적 초점거리가 바뀌지는 않습니다.

**Connect → 컨트롤러**에서는 Quest 메뉴의 포인터 모양과 보정, 손 추적, 주로 사용하는 손을 설정합니다. 이전의 ‘버튼 설정’은 PC 게임패드 매핑 항목이 잘못 표시된 것이어서 제거했습니다. 현재 버전에서는 Quest로 PC 마우스, 키보드, 게임패드를 조작할 수 없습니다.

## 숨기기와 종료

**Settings → 트레이로 보내기**를 누르면 설정창만 숨겨지고 영상 전송은 계속됩니다. 바로가기나 트레이 메뉴에서 창을 다시 열 수 있습니다. **PC 중지**를 누르면 영상 처리와 전송이 정상적으로 종료됩니다. 전송 중 창을 닫을 때는 **트레이 / 중지 후 종료 / 취소** 중 하나를 선택합니다.

## 문제 해결

- **PC 검색 실패:** PC와 Quest를 같은 공유기에 연결하고, PC 앱에 표시된 주소를 Quest에 입력하세요. 처음 설치했다면 설치창의 **연결 허용**을 확인하세요. Windows 네트워크를 ‘개인(Private)’으로 설정하는 것은 신뢰하는 집 네트워크에서만 권장합니다.
- **PIN 실패:** Quest 한 대에서 새 연결 요청을 만들고 새 PIN을 입력하세요. Sterevi는 여러 요청이나 이전 PIN을 자동으로 승인하지 않습니다.
- **검은 영상:** PC에서는 정상인데 Quest에서만 검게 보인다면 브라우저의 캡처 제한이나 GPU 호환성이 원인일 수 있습니다. 개발 환경에서는 브라우저 하드웨어 가속을 꺼서 해결했지만, 모든 콘텐츠의 재생을 보장하지는 않습니다.
- **윤곽 흐림:** Depth를 낮추고 윤곽 안정화를 켜 보세요. 불편하면 2D로 전환하세요.
- **시작/중지 오류:** 오류 안내를 확인하고 진단을 저장한 뒤 로그를 살펴보세요. 다른 Sunshine 서버가 같은 포트를 쓰고 있다면 그 프로그램을 정상적으로 종료하세요.
- **이전 실행 기록 손상:** 이미 종료된 실행의 상태 기록은 자동으로 건너뛰고 새 실행을 준비합니다. 작업이 실행 중이거나 어느 실행의 기록인지 확인할 수 없으면 중복 시작을 막습니다. 오류가 계속되면 진단을 저장하세요.
- **모니터 연결 변경 후 시작 실패:** **Display → Monitor**에서 해상도를 확인하고 사용할 16:9 화면을 다시 선택하세요. 모니터 연결을 바꾸면 Windows의 모니터 번호도 바뀔 수 있습니다.

PC 설정은 `config/desktop.json`에, Quest 설정은 헤드셋 앱에 저장됩니다. 업데이트할 때 앱 데이터를 지우지 마세요. 개인 페어링 정보와 인증 파일은 다른 PC에 복사하지 마세요.
