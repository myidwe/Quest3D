# Quest3D 사용 방법

처음 설치는 [설치 안내](DISTRIBUTION.md)를 참고합니다.

## 매번 사용하는 순서

1. 바탕화면이나 시작 메뉴의 **Quest3D Desktop**을 엽니다.
2. **PC 시작**을 누르고 영상 준비를 기다립니다.
3. Quest 앱에서 이 PC의 **Connect**를 누릅니다.

처음 연결하는 Quest는 **Select Server → Scan Network → 검색된 PC 선택**으로 Pair를 진행합니다. PC 앱의 **Connection → 새 Quest 연결**에 헤드셋의 네 자리 PIN을 입력합니다. PC 시작이 끝나야 승인할 수 있습니다. PIN 승인 뒤 실제 연결 완료는 Quest에서 확인하세요. 연결 정보는 다음 실행에도 유지됩니다. 네트워크에서 자동 검색을 지원하지 않으면 **+**의 주소 입력을 보조 수단으로 사용합니다.

## Quest 2 / Quest 3 선택

1. 송출 중이면 **PC 중지**를 누릅니다.
2. PC 앱의 **Settings → Quality → Headset**에서 **Quest 2** 또는 **Quest 3**를 선택합니다.
3. **PC 시작** 후 Quest에서 **Connect**를 누릅니다.

Quest 2는 눈별1920×1080, Quest 3는 눈별2048×1152로 PC 영상을 보냅니다. 둘 다16:9이며 Depth%와 윤곽 안정화는 유지합니다. 기존 PC 설정은 Quest 2가 기본입니다. 높은 해상도에서 부드러움이 아쉽거나 Quest 2로 돌아갈 때는 같은 순서로 Quest 2를 선택합니다. 모니터 선택도 송출을 중지한 상태에서 변경합니다.

Quest 3의4096×1152 Full SBS 전송은 **HEVC**를 사용합니다. Quest의 **Quality**에서 코덱을 확인하세요. 이 숫자는 좌우 영상을 합친 전송 크기이며, 실제 감상 화면의 눈별 비율은16:9입니다. 패널 전체 해상도나 설정창 크기와는 다릅니다.

새 Quest 3에는 앱을 설치한 뒤 해당 헤드셋에서 처음 페어링해야 합니다. 기존 Quest 2의 인증 파일을 복사하지 않습니다. **PC 시작 → Quest Select Server → Scan Network → 검색된 PC 선택 → PC Connection에서 새 PIN 승인** 순서입니다. PIN 화면은 승인될 때까지 유지하고, 자동 연결되지 않으면 Quest에서 Connect를 누릅니다. USB는 설치·진단용이며 현재 영상 전송에는 PC와 Quest가 같은 사설 네트워크에 있어야 합니다.

## Sound · 소리 출력

**PC 중지 → Settings → Sound → 출력 선택 → PC 시작 → Quest Connect**

| 출력 | 동작 |
|---|---|
| PC · 기본 | 기존 PC 스피커·헤드폰 사용 |
| Quest only | 연결 중 Quest 전용, 연결 종료 시 PC 출력 복원 |
| PC + Quest | PC와 Quest 동시 재생 |

Quest 음량은 헤드셋 볼륨 버튼으로 조절합니다. Quest only는 설치된 Steam Streaming Speakers가 필요하며, 준비되지 않은 PC에는 이유가 표시됩니다. PC와 Quest를 함께 재생하면 소리가 겹칠 수 있습니다.

Quest only에서도 특정 앱의 소리만 PC에 남으면 Windows 음량 믹서에서 그 앱의 출력을 **기본값**으로 선택하고 재생을 다시 시작합니다. 앱별로 고정된 출력 장치까지 강제로 변경하지 않습니다. 소리가 돌아오지 않으면 **PC 중지** 후 상태를 확인하고 진단을 저장합니다.

## 화질 조절

**Settings → Quality → AI Quality**는 Standard / Quality · Preview를 선택합니다. PC 중지 후 변경·재시작이 필요합니다. Standard는 속도, Quality는 더 높은 AI 분석 해상도를 사용하며 눈별 송출 크기는 그대로입니다. Quality가 모든 장면에서 더 좋거나 일정 FPS를 보장하는 설정은 아닙니다.

**Settings → Quality → Depth model**에서 **DAv2 Small (기본)** / **DAD Small (비교)**를 선택할 수 있습니다. 설치된 모델은 송출 중에도 재연결 없이 전환됩니다. 같은 장면·Depth로 비교하고, 윤곽과 입체감이 더 자연스러운 모델을 사용하세요. DAD는 장면에 따라 입체감도 줄어들 수 있습니다. 중지 상태의 선택은 다음 PC 시작에 적용됩니다. 미설치 항목은 선택할 수 없습니다.

| 조절 | 의미 |
|---|---|
| Mode · 2D / 3D | 같은 화면에서 원본과 입체를 전환합니다. |
| Depth | 입체감 조절. −/+로 0.05%p씩 조절합니다. PC에서는 숫자 입력 후 Enter 또는 슬라이더로 조절할 수도 있습니다. 윤곽이 겹치면 조금 낮춰 보세요. |
| 윤곽 안정화 | 경계의 과한 양안 차이를 줄입니다. 입체감이 조금 약해질 수 있습니다. |
| 모니터 | PC 송출을 중지한 뒤 선택합니다. 현재 지원 비율은 16:9입니다. |
| Settings · Quality · Headset | 송출 중지 후 Quest 2/Quest 3 출력 해상도 선택. PC 재시작·Quest 재연결 후 적용합니다. |
| Settings · 진단 | 눈별 해상도·처리 상태·진단을 확인합니다. 게시 빈도는 새 AI 영상의 FPS와 다릅니다. |

Quest의 **Display**에서 2D/3D·Depth·크기·거리, **3D**에서 입체 세부 설정, **Quality**에서 전송·선명도·색감을 조절합니다. 메뉴 하단의 **메뉴 이동** 손잡이를 트리거로 잡고 이동할 수 있습니다. 설정 화면은 다크 모드가 기본이며 영상 색감과는 별개입니다. 기존 HEVC·해상도·색·화면 위치 설정은 유지합니다.

Display의 상세 설정에서 위치·곡률·여백·보기 저장을 사용할 수 있습니다. 기본 Alignment · Level은 Center·이동 때 수평을 유지합니다. 누워 보거나 의도적으로 기울일 때만 Free를 선택합니다. 영상 크기와 메뉴 배율·포인터 크기는 별도로 조절합니다.

**Connect → 컨트롤러**에서는 Quest 메뉴의 포인터 모양·보정, 손 추적, 주 사용 손을 조절합니다. 이전의 ‘버튼 설정’은 PC 게임패드 매핑을 잘못 노출한 항목으로 제거했습니다. 현재 버전은 Quest에서 PC 마우스·키보드·게임패드 입력을 조작하는 기능을 제공하지 않습니다.

## 숨기기와 종료

**Settings → 트레이로 보내기**는 설정창만 숨기고 송출을 계속합니다. 바로가기나 트레이 메뉴에서 다시 엽니다. **PC 중지**는 송출과 영상 처리를 정상 종료합니다. 송출 중 창을 닫으면 **트레이 / 중지 후 종료 / 취소**를 선택합니다.

## 문제 해결

- **PC 검색 실패:** 같은 공유기에 연결하고 PC 앱 주소를 Quest에 입력합니다. 새 설치는 설치창의 연결 허용을 확인합니다. 신뢰하는 집 네트워크만 Windows 사설망으로 설정하세요.
- **PIN 실패:** Quest 한 대에서 새 연결을 열고 새 PIN을 입력합니다. 여러 요청이나 이전 PIN을 자동으로 승인하지 않습니다.
- **검은 영상:** PC 원본은 정상인데 Quest만 검으면 브라우저 캡처 제한 또는 GPU 호환성일 수 있습니다. 현재 환경은 하드웨어 가속 해제로 해결됐지만 모든 콘텐츠를 지원하지는 않습니다.
- **윤곽 흐림:** 입체감을 낮추고 윤곽 안정화를 사용합니다. 불편하면 2D로 전환하세요.
- **시작/중지 오류:** 안내를 읽고 진단 저장 후 로그를 확인합니다. 다른 Sunshine 서버와 포트가 겹치면 그 프로그램을 정상 종료하세요.
- **이전 실행 기록 손상:** 종료된 실행의 상태 기록은 자동으로 건너뛰고 새 실행을 준비합니다. 실행 중인 작업이 있거나 신원을 확인할 수 없으면 중복 시작을 막습니다. 오류가 남으면 진단을 저장하세요.
- **모니터 연결 변경 후 시작 실패:** Display의 Monitor에서 해상도를 확인하고 사용할 16:9 화면을 다시 선택합니다. Windows의 모니터 번호가 바뀔 수 있습니다.

PC 설정은 `config/desktop.json`, Quest 설정은 헤드셋 앱에 저장됩니다. 업데이트 때 앱 데이터를 지우지 마세요. 개인 페어링/인증 파일을 다른 PC에 복사하지 않습니다.
