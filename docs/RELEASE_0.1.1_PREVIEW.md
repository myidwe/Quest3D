# 0.1.1-preview

개인정보 수정 배포 · 2026-10-01

공개 Quest APK에 남은 빌드 계정명·경로를 제거하는 수정 배포다. 기존 기능·영상 설정·페어링은 보존한다. [개인정보 수정 내역](PRIVACY_REMEDIATION_2026-10-01.md)에 문제와 처리 방법을 기록한다.

공개 package는 `app.questto3d.client`, versionCode는 3이다. 같은 공개 서명키를 사용하므로 기존 공개 앱에 덮어 설치한다. 개발 앱은 별도 package로 유지한다. Desktop도 같은 버전의 ZIP으로 업데이트하며 기존 설정·모델·인증서는 유지한다.

공유용 진단 파일은 로컬 경로·연결 주소·기기 식별자·인증 정보를 가린 사본이다. 원본 로그는 PC에 유지한다. 가림은 임의의 텍스트에 대한 완전한 개인정보 제거 보증이 아니므로 공유 전 내용을 확인한다.

지원 장비와 기능 범위는 0.1.0-preview와 같다. Windows x64·NVIDIA Turing(sm75), 같은 사설 LAN, 현재 16:9 모니터를 대상으로 한다. 새 Windows·다른 PC/GPU·새 공개 APK의 Quest 2·정량 AV 오차·장시간 안정성의 미검증 상태를 유지한다. 성능이나 입체 품질 향상을 주장하는 릴리스가 아니다.

최종 배포 파일은 Release의 체크섬·검증 기록을 확인한다. 체크섬·개인정보·설치 검증은 각 기록의 실제 대상 파일 해시를 따른다.
