# Product scope — 공개 Preview 준비안

기준일: 2026-09-30. 현재 구현과 검증 범위를 정리한 문서이며 정식 출시 선언이 아니다.

## 사용 흐름

PC 앱에서 모니터·헤드셋·품질·소리 출력을 선택하고 PC 시작을 누른다. Quest는 같은 사설망에서 PC를 검색·페어링한 뒤 Connect한다. 기존 브라우저와 프로그램을 큰 화면으로 보고 같은 화면에서 2D/3D·Depth를 조절한다. 종료 시 PC 중지로 영상 처리와 송출을 함께 멈춘다.

## 구성

| 구성 | 역할 |
|---|---|
| Windows Python/PySide6/QML | 시작·중지·설정·연결·진단 |
| GPU 캡처·PyTorch·CUDA 합성 | 모니터 캡처, 깊이 추론, 좌우 영상, 공유 메모리 게시 |
| Sunshine 수정본 | NVENC·HEVC/H.264, 네트워크 전송, 선택형 loopback 오디오 |
| Nightfall/Godot 수정본 | Quest 디코딩·눈별 표시, 화면·메뉴 조절 |

서로 설치하는 것만으로 통합되는 제품이 아니다. 공유 메모리 계약·타임스탬프·제어·오디오·연결 수명을 연결하는 Quest3D 수정 코드가 필요하다.

## 새 설치 기본값

Quest 2 프로필, DAv2 Small, Standard AI, comfort 윤곽 안정화, Depth 약1.31%, PC 소리. Quest 3에서는 PC 중지 후 Headset을 Quest 3로 바꾸고 HEVC로 연결한다. 개발자의 모니터·DAD·Quality·Depth·인증 정보는 복사하지 않는다.

## 포함 범위

선택 모니터 전체 캡처·큰 화면 감상, 실제 로컬 깊이 AI, 2D/3D, Depth·윤곽·화질·색감, Quest 화면 위치·크기·보기 저장·수평 정렬, PC/Quest 오디오 출력, 설치·시작·중지·페어링·진단.

## 제외 범위

Quest에서 PC 클릭·드래그·스크롤, 내장 파일 플레이어, 원래 창 안 선택 영역의 입체화, 완전한 공간 재구성, 별도 AV 오차 보정. DRM·보호 화면 우회는 구현 범위가 아니다. 현재 GPU 경로는 Turing sm75, 모니터 비율은16:9로 제한된다.

## 검증 구분

Quest 2·Quest 3에서 실제 영상과 입체감을 사용자에게 확인받았다. 최신 Quest 3 APK는 설치·시작·설정 보존과 compiled 검사까지 확인했다. 최근 UI의 착용 평가·Quest 2 재검증·소리 청취·AV 오차·장시간·다른 PC 설치는 남아 있다. PC의 새 3D FPS, 반복 게시, Quest 수신, 헤드셋 표시율을 별도로 기록한다.
