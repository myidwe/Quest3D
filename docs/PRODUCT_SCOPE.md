# Sterevi 기능과 지원 범위

기준일: 2026-10-01. 이 문서는 현재 기능과 지원 범위를 정리합니다. Preview 버전에는 실제 기기 검증이 남아 있습니다. 각 배포 파일의 검증 상태는 해당 Release의 `release-validation.json`에서 확인할 수 있습니다.

## 사용 흐름

PC 앱에서 모니터, 헤드셋, 화질, 소리 출력을 선택하고 **PC 시작**을 누릅니다. Quest를 같은 사설망에 연결한 뒤 PC를 검색하고 페어링합니다. **Connect**를 누르면 기존 브라우저와 프로그램을 큰 화면으로 볼 수 있습니다.

Quest에서 2D/3D를 전환하고 Depth를 조절할 수 있습니다. 사용을 마치면 PC 앱의 **PC 중지**를 눌러 영상 처리와 송출을 함께 종료합니다.

## 구성

| 구성 | 역할 |
|---|---|
| Windows Python/PySide6/QML | 시작·중지·설정·연결·진단 |
| GPU 캡처·PyTorch·CUDA 합성 | 모니터 캡처, 깊이 추론, 좌우 영상 생성, 공유 메모리 전달 |
| Sunshine 수정본 | NVENC·HEVC/H.264 인코딩, 네트워크 전송, 선택한 출력 장치의 소리 캡처(loopback) |
| Nightfall/Godot 수정본 | Quest 영상 디코딩과 좌우 눈별 표시, 화면·메뉴 조절 |

Sterevi의 수정 코드가 각 구성 요소를 연결합니다. 공유 메모리 형식, 타임스탬프, 설정 제어, 오디오, 연결 시작과 종료를 맞춰야 하므로 원본 프로그램을 각각 설치하는 것만으로는 같은 기능을 사용할 수 없습니다.

## 새 설치 기본값

새로 설치하면 Quest 2 프로필, DAv2 Small, Standard AI, comfort 윤곽 안정화, Depth 약 1.31%, PC 소리로 설정됩니다. Quest 3를 사용할 때는 **PC 중지**를 누른 뒤 **Headset**을 **Quest 3**로 바꾸고 HEVC로 연결합니다. 개발 환경에서 사용한 모니터·DAD·Quality·Depth 설정이나 인증 정보는 설치본에 포함하지 않습니다.

## 포함 범위

- 선택한 모니터 전체를 캡처해 Quest의 큰 화면으로 감상
- 로컬 AI 깊이 추론과 2D/3D 전환
- Depth, 윤곽 안정화, 화질, 색감 조절
- Quest 화면의 위치·크기 조절, 보기 저장, 수평 정렬
- PC/Quest 소리 출력 설정
- 설치, 시작·중지, 페어링, 연결 진단

## 제외 범위

Quest에서 PC를 클릭·드래그·스크롤하는 기능, 내장 파일 플레이어, 원래 창 안에서 선택 영역만 입체화하는 기능, 완전한 공간 재구성, 별도의 영상·음성 오차 보정은 지원하지 않습니다. DRM이나 보호된 화면을 우회하는 기능도 제공하지 않습니다. 현재 GPU 처리 경로는 Turing sm75, 모니터 화면비는 16:9로 제한됩니다.

## 검증 구분

기존 개발 앱은 사용자가 Quest 2·Quest 3를 착용해 영상과 입체감을 확인했습니다. 새 공개 앱은 개발 앱과 다른 패키지, 장기 서명, 공개 헤더 기반 vendor를 사용하므로 공개 APK도 별도로 검증해야 합니다.

배포 검증에서는 실제 캡처와 AI 추론, 네이티브 대응 소스, 설치, Quest 수신, 착용 확인, 소리를 각각 기록합니다. PC에서 새 3D 프레임을 생성하는 FPS, 같은 프레임의 반복 송출, Quest 수신율, 헤드셋 표시율도 구분합니다. 다른 PC, 최신 공개 APK의 Quest 2 사용, 영상·음성 오차, 장시간 사용 등 아직 확인하지 못한 항목은 Preview의 제한으로 남깁니다.
