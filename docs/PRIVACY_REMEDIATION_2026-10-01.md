# 공개 배포 개인정보 제거

수정 배포의 검증 기준 · 2026-10-01

## 확인된 문제

0.1.0-preview Quest APK의 stream 네이티브 라이브러리에 빌드 계정명과 Linux 홈 경로가 남았다. APK와 Quest 설치 ZIP에 같은 라이브러리가 들어 있었다. 소스 저장소에서 이 계정 경로나 실제 이메일·기기 일련번호·개인키·인증 토큰의 공개는 확인되지 않았다. 계정명 검색 결과는 82회였으며 비밀번호 노출로 해석하지 않는다.

문제가 있는 APK와 Quest ZIP의 공개 다운로드를 중단했다. 기존 대응 소스와 라이선스 고지는 이미 받은 사용자가 확인할 수 있도록 유지한다. 기존 체크섬·검증 파일은 철회 전 파일을 설명하는 기록이다. 이미 내려받은 사본은 원격 삭제할 수 없다.

## 수정 방법

- 고정 버전의 stream 및 정적 의존성 13개를 새 출력·캐시에서 재빌드
- 컴파일러 파일·매크로·디버그 경로를 일반적인 빌드 경로로 변환
- OpenSSL 생성 빌드 정보에 개인 경로가 포함된 compiler command가 들어가지 않도록 소스에서 수정
- 최종 ELF 바이트 치환과 assertion 제거는 사용하지 않음
- 공유용 진단에 경로·주소·기기 식별자·인증 정보 가림 적용, 로컬 원본·설정·페어링 유지
- 앱이 시작하는 PowerShell의 telemetry opt-out 적용, 시스템 설정은 변경하지 않음
- 공개 소스·최종 signed APK·중첩 ZIP·UTF-16·Godot 컴파일 리소스 검사 추가

공식 의존성의 저작권 표시·저자 연락처와 공개 테스트 키는 실제 출처·정확한 해시를 확인하여 구분한다. 소유자 식별자는 출처 예외로 통과시킬 수 없다. 임의의 암호화·난독화 데이터에 알려지지 않은 개인정보가 전혀 없음을 증명하는 검사는 아니다.

## 업데이트

수정본은 0.1.1-preview, 공개 package `app.questto3d.client`, versionCode 3으로 준비한다. 기존 공개 인증서와 동일하게 서명하여 데이터 보존 업데이트를 제공한다. 인증서 SHA-256은 `d950d11633753a3a52acba925dff8a35ccc0df7de1aef77291a1868c93f73cfc`다.

최종 파일과 검증 완료 여부는 새 Release의 `SHA256SUMS.txt`, `release-validation.json`, `privacy-audit.json`으로 확인한다. 재빌드 성공만으로 설치·영상·음성·실기 검증을 완료했다고 판단하지 않는다. 게시 상태와 최신 검증 결과는 같은 버전의 Release를 따른다.
