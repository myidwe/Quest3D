# Sterevi 설치·배포 안내

처음 설치한다면 [처음 설치와 연결](GETTING_STARTED.md)을 먼저 확인하세요. 이 문서에서는 설치 조건, 업데이트, 복구와 제거 방법을 자세히 설명합니다. 다른 안내는 [문서 목차](README.md)에 있습니다.

현재 안내는 **0.1.3-preview** 기준입니다. [해당 버전의 Release](https://github.com/myidwe/Sterevi/releases/tag/v0.1.3-preview)에서 Desktop Setup EXE와 Quest Setup EXE를 받으세요. Quest는 APK를 직접 받아 설치할 수도 있으며, ZIP은 수동 설치용입니다. 지원 범위와 실제 검증 결과는 [배포 안내](RELEASE_0.1.3_PREVIEW.md)와 Release의 `release-validation.json`에 정리했습니다. 이전 이름으로 설치한 경우에도 기존 설치 폴더를 선택해 업데이트하면 설정, 모델, 페어링 정보가 유지됩니다.

## 받을 파일

GitHub **Releases**에서 같은 버전의 파일을 받으세요. EXE는 압축을 풀지 않고 실행하면 됩니다. Quest APK는 기존 공개 앱과 같은 패키지와 서명을 사용하며, 버전은 0.1.3-preview, versionCode는 4입니다. APK를 직접 설치할 때는 [APK 설치 안내](GETTING_STARTED.md#apk-직접-설치)를, EXE에 관한 자세한 내용은 [EXE 설치·빌드·검증](EXE_INSTALLERS.md)을 확인하세요. GitHub의 **Code → Download ZIP**으로 받는 파일은 개발용 소스이며 설치 파일이 아닙니다. [GitHub 공식 Release 안내](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)에서도 두 방식의 차이를 확인할 수 있습니다.

| 파일 | 용도 |
|---|---|
| `Sterevi-Desktop-Setup-<version>.exe` | Windows 앱 설치 |
| `Sterevi-Quest-Setup-<version>.exe` | Quest USB 설치 |
| `Sterevi-Quest-<version>.apk` | 기존 설치 도구·ADB로 직접 설치 |
| `Sterevi-Desktop-<version>.zip` | 수동 설치용 Windows 묶음 |
| `Sterevi-Quest-<version>.zip` | Quest APK와 USB 설치 도구 |
| `Sterevi-Source-<version>.zip` | 배포된 실행 파일에 해당하는 소스 코드(대응 소스), 라이선스 고지와 빌드 자료 |
| `SHA256SUMS.txt` | 다운로드 파일의 SHA-256 확인 |
| `release-validation.json` | 설치·동작 검증 결과와 아직 확인하지 못한 조건 |
| `privacy-audit.json` | 최종 APK·ZIP의 개인정보 검사 결과 |

ZIP에는 모델 가중치, 개인 인증서, 페어링 정보, 미디어와 사용 로그를 넣지 않습니다. PC를 처음 설치할 때 정해진 모델을 다운로드하고, 이후 AI 처리는 PC에서 실행합니다. 앱 구독료와 클라우드 추론료는 없습니다.

## 사용 조건

| 항목 | 현재 범위 |
|---|---|
| PC | Windows x64. Windows 11과 RTX 2060 SUPER 8 GB 조합에서 실제 동작 확인 |
| GPU | NVIDIA Turing **sm75 / Compute Capability 7.5**만 실행 허용. 다른 Turing GPU의 VRAM, NVENC와 처리 속도는 미검증 |
| 모니터 | **16:9** 화면만 지원. 다른 화면비는 PC 시작 단계에서 차단 |
| 헤드셋 | Quest 2 / Quest 3. 이전 버전의 영상 연결과 입체감 확인. 최신 APK의 Quest 2 재검증은 별도 필요 |
| 연결 | PC와 Quest가 같은 공유기의 로컬 네트워크에 연결되어 있어야 함. PC는 유선, Quest는 안정적인 Wi-Fi 연결 권장. USB는 설치·진단용 |
| 설치 | 첫 다운로드에 수 GB 사용. 설치 파일과 캐시를 저장할 공간도 필요. 최소 RAM, 디스크 공간과 드라이버 버전은 공개 후보의 실측 전까지 미확정 |

현재 AMD·Intel GPU, Turing 이외의 NVIDIA GPU, ARM Windows와 macOS/Linux 호스트는 지원하지 않습니다. RTX 30/40/50 계열도 CUDA를 지원한다는 이유만으로 실행할 수 있는 것은 아닙니다. 설치 과정에서 실제 CUDA 커널을 실행해 호환성을 검사합니다.

PC 영상의 눈별 전송 해상도는 Quest 2가 **1920×1080**, Quest 3가 **2048×1152**입니다. Quest 3에는 좌우 영상을 합친 **4096×1152 Full SBS** 영상을 HEVC로 전송합니다. 전송 해상도는 헤드셋 패널의 해상도와 다릅니다. AI가 새 영상을 만드는 FPS, 같은 프레임을 포함해 반복 전송하는 FPS, 헤드셋 화면의 주사율도 구분해야 합니다.

## PC 처음 설치

호환되는 Python 3.12.6(x64·Tk)이 이미 설치되어 있으면 재사용합니다. Windows에 등록된 Python 3.12가 손상되었거나 버전이 다를 때는 다른 프로그램의 환경을 보호하기 위해 자동 재설치를 중단합니다. 이 경우 오류 로그의 안내에 따라 기존 환경을 복구하거나, 설치 명령의 `-Python` 옵션으로 호환되는 Python 경로를 지정하세요. 기존 Python 폴더를 삭제하지 마세요.

<details>
<summary>이전 설치 후보의 측정 기록</summary>

10월1일 새 호스트 후보는 개발 PC의 별도 A 드라이브 폴더에서 기존 Python3.12.6을 지정해 약3분54초에 설치했다. 고정 라이브러리·모델 새 다운로드, CUDA7종·Qt 화면을 통과했고 이후 실제 캡처·모델 추론·송출 시작도 확인했다. 이전 후보의 약10분7초와 조건이 같지는 않으며 설치 시간을 보장하지 않는다. 인터넷·디스크·기존 Python 상태에 따라 달라진다. 이전 설치·cache 명목 합계는 약10.7GiB였고 하드링크를 포함하므로 최소 공간 요구와 같지 않다. 업데이트 백업도 공간을 사용한다. Python 없는 새 Windows의 자동 설치·등록 검증은 남아 있다.

</details>

1. **Desktop Setup EXE**를 실행합니다. 설치 파일을 자동으로 검사하고 풀어 설치창을 엽니다.
2. 폴더와 바로가기를 확인하고 **설치**를 누릅니다. 새 설치의 기본 폴더는 `%LOCALAPPDATA%\Sterevi Desktop`입니다. 기존 설치가 감지되면 그 폴더를 업데이트합니다. 공간이 부족하다면 A 드라이브 등 다른 드라이브의 비어 있는 전용 폴더를 선택하세요. 경로에 `#`, 따옴표, 줄바꿈은 사용할 수 없습니다.
3. Python **3.12.6 x64**, 정해진 버전의 GPU 라이브러리와 Depth Anything V2 Small(약 99 MB)을 다운로드합니다. **설치 로그**에서 진행 상황과 오류를 확인할 수 있습니다. CUDA 검사와 실제 앱 화면 검사까지 통과해야 설치가 완료됩니다.
4. **연결 허용**을 누릅니다. 버튼 안내에서 허용 범위를 확인할 수 있습니다. 올바른 방화벽 규칙이 이미 있으면 관리자 승인도 생략하며, 변경이나 관리자 재확인이 필요할 때만 Windows 승인을 요청합니다. 허용 범위는 개인(Private) 네트워크의 로컬 서브넷에서 사용하는 앱 스트리밍 포트뿐입니다. 공용 네트워크와 관리 페이지는 열지 않습니다.
5. **앱 실행** 또는 **Sterevi Desktop** 바로가기를 열고 설치창을 닫습니다. PC가 중지된 상태에서 **Settings → Quality → Headset**의 Quest 2 / Quest 3를 선택하고 모니터를 확인합니다.
6. **PC 시작**을 누르고 영상이 준비되면 Quest에서 **Pair** 또는 **Connect**를 누릅니다.

평소 사용할 때는 Codex, 터미널, Unity, WSL 등 개발 도구가 필요하지 않습니다. 설치 도구는 Windows 자동 시작, 서비스와 브라우저 설정을 변경하지 않습니다. 방화벽 변경은 사용자가 **연결 허용**을 눌렀을 때 요청합니다.

설치창은 실행 파일과 설치 소유권을 확인하고, 관리자 권한으로 실행한 작업의 종료 코드와 새 결과를 확인합니다. UAC를 승인하는 것만으로 방화벽 적용이나 실제 연결이 성공했다고 표시하지 않습니다. 취소, 실패, 일부만 적용된 경우에는 미완료로 표시하고 기존 설정과 개인 데이터를 보존합니다. 규칙을 조회하지 못한 경우와 규칙이 없는 경우도 구분합니다.

개발 PC에서는 방화벽 적용과 적용 후 상태 검사를 통과했습니다. 새 Windows에서 내려받은 파일의 첫 실행, Python 공식 설치기, 다른 관리자 계정과 사용자의 UAC 취소는 아직 검증하지 못했습니다. Python은 일반 사용자용으로 설치하지만, 시스템 C Runtime을 보완할 때는 예외적으로 관리자 승인이 필요할 수 있습니다. 평소 앱을 실행할 때는 관리자 모드를 사용하지 않아도 됩니다. 자세한 범위는 [설정과 권한](SETUP_PERMISSIONS_2026-09-30.md)을 확인하세요.

**연결 허용**으로 여는 포트는 TCP `47984/47989/48010`, UDP `47998/47999/48000`입니다. 자동 검색에는 mDNS도 사용하며, 개발 PC에서는 Windows DNS Client의 기존 개인 네트워크 UDP 5353 규칙을 이용했습니다. 다른 PC의 mDNS 정책이나 게스트 Wi-Fi의 기기 간 통신 제한은 별도로 확인해야 합니다. **Scan Network**로 검색되지 않으면 PC 주소를 직접 입력할 수 있습니다.

## Quest 처음 설치

1. Meta의 개발자 팀·계정 확인 요건을 갖춘 뒤, 모바일 **Meta Horizon 앱 → 헤드셋 설정 → 개발자 모드**를 켭니다. 현재 요건과 메뉴는 [Meta 공식 기기 설정](https://developers.meta.com/vr/documentation/native/android/mobile-device-setup/)을 확인하세요.
2. Windows용 **Oculus ADB Drivers**를 준비합니다. Meta 공식 기기 설정에 안내된 링크와 설치 절차를 따르세요. Sterevi 설치기는 드라이버를 자동으로 설치하지 않습니다.
3. USB 데이터 케이블로 Quest를 연결하고 헤드셋 안에서 **USB 디버깅 허용**을 누릅니다.
4. [Google 공식 Android Platform Tools](https://developer.android.com/tools/releases/platform-tools)를 다운로드하고 압축을 풉니다. Android Studio 전체를 설치할 필요는 없습니다.
5. **Quest Setup EXE**를 열고 `adb.exe`를 선택합니다. **기기 검색 → 설치할 Quest 선택 → Quest에 설치** 순서로 진행하세요. 여러 기기가 연결되어 있다면 설치할 Quest를 직접 선택해야 합니다. ZIP으로 설치한다면 압축을 모두 풀고 `Install-Quest.cmd`를 엽니다.
6. 헤드셋 앱 목록의 **알 수 없는 출처 → Sterevi**를 엽니다. 앱 목록의 위치와 표기는 Horizon OS 버전에 따라 다를 수 있습니다.

개발자 모드와 USB 디버깅은 기기 소유자가 직접 설정하고 승인해야 합니다. 설치창은 승인 대기 중인 기기, 오프라인 기기와 다른 Android 기기를 구분하고, 승인된 Quest에만 설치합니다. 설치 도구는 APK 해시, 기기 종류와 버전 기록을 확인한 뒤 `adb install -r`로 설치합니다. 이전 versionCode로 되돌리거나 기존 앱을 자동으로 삭제하거나 데이터를 초기화하지 않습니다.

USB 디버깅 승인은 해당 PC가 Quest에 앱을 설치하고 디버깅할 수 있도록 허용하는 설정입니다. 앱의 PIN 페어링이나 MTP 파일 접근 승인과는 별개입니다. 확인한 최신 개발 APK의 manifest에는 마이크, 카메라, 외부 저장소와 Scene 권한이 없습니다. PC 소리를 받기 위해 마이크 승인을 요구하지 않습니다. 새로 설치한 앱의 첫 실행 때 나오는 시스템 안내는 별도로 검증해야 합니다. 현재 PC·Quest 설치창에서는 작업을 시작한 뒤 취소할 수 없으므로, 완료되거나 실패할 때까지 기다린 뒤 다시 시도하세요.

기존 개발 앱의 패키지는 `app.questto3d.client.debug`입니다. 공개 앱은 `app.questto3d.client`로 별도 설치하며 기존 개발 앱을 삭제하지 않습니다. 공개 앱에서는 PC를 다시 검색하고 페어링하세요. 이후 공개 앱 업데이트는 같은 패키지와 공개 서명키를 유지하고 versionCode를 높여 설치합니다. 개발 앱의 설정과 페어링 정보는 공개 앱으로 자동 이전되지 않습니다.

## 첫 연결과 매번 사용

평소에는 **PC 앱 → PC 시작 → Quest 앱의 Connect** 순서로 사용합니다.

새 헤드셋은 **Select Server → Scan Network → 검색된 PC → Pair** 순서로 연결합니다. PC가 검색되지 않으면 **+** 버튼을 눌러 PC 앱에 표시된 주소를 입력하세요. 헤드셋의 네 자리 PIN을 PC 앱의 **Connection → 새 Quest 연결**에 입력하고 승인합니다. 승인될 때까지 Quest의 PIN 화면을 열어 두고, 자동으로 연결되지 않으면 **Connect**를 누릅니다. PC와 헤드셋의 조합마다 처음 한 번은 페어링이 필요합니다.

연결 후에는 2D/3D, Depth와 윤곽 안정화를 조절할 수 있습니다. Quest의 **Display**에서는 크기, 거리, 위치, 곡률과 여백을 조절하고 현재 화면 설정을 저장합니다. **Quality**에서는 선명도, 색감과 전송 설정을 바꿉니다. 설정창은 세로로 구성되어 있습니다. 기본값인 **Level**에서는 수평을 유지하고, **Free**를 선택하면 기울기를 조절할 수 있습니다. 자세한 사용법은 [사용 안내](DESKTOP_USER_GUIDE.md)를 확인하세요.

창을 숨겨도 영상 전송은 계속됩니다. **PC 중지 / 중지 후 종료**를 누르면 정상적으로 종료합니다. 현재 버전에는 Quest에서 Windows를 클릭·드래그·스크롤하는 기능, 내장 영상·사진 플레이어, 원래 화면의 선택 영역만 입체화하는 기능은 없습니다.

## Sound · 소리 출력

**PC 중지 → Settings → Sound → 출력 선택 → PC 시작 → Quest Connect** 순서로 적용합니다.

| 선택 | 동작·조건 |
|---|---|
| PC · 기본 | 기존 PC 스피커나 헤드폰에서 재생. Quest에는 소리를 전송하지 않음 |
| PC + Quest | PC 기본 출력 장치와 Quest에서 함께 재생. 소리가 겹칠 수 있음 |
| Quest only | 연결 중에는 기존 가상 출력 장치를 통해 Quest에서만 재생. 연결이 끝나거나 PC를 중지하면 PC 출력으로 복원 |

Quest only를 사용하려면 **Steam Streaming Speakers가 이미 설치되어 있고 활성화되어 있어야 합니다.** ZIP에는 이 드라이버가 없으며 자동으로 설치하지도 않습니다. PC에 준비되어 있지 않으면 해당 옵션이 비활성화되고 이유가 표시됩니다. 드라이버의 공개 설치와 재배포 방식은 추가 검토가 필요하므로 필수 설치 단계에는 포함하지 않습니다.

Quest 음량은 헤드셋 볼륨 버튼으로 조절합니다. 특정 앱에 출력 장치가 따로 지정되어 있다면 Windows 음량 믹서에서 **기본값**으로 바꾸고 재생을 다시 시작하세요. Sterevi는 앱별 출력 장치를 강제로 바꾸지 않습니다. 개발 PC와 Quest 3에서는 소리 수신과 장치 복원을 확인했습니다. 다만 헤드셋을 착용한 청취, 영상과 소리의 시간 차이, 장시간 사용과 최신 Quest 2 검증은 남아 있습니다. 음성 지연 조절 기능도 완료된 상태는 아닙니다.

## AI Quality와 선택 모델

기본 모델은 **DAv2 Small**입니다. **PC 중지**를 누른 뒤 **Settings → Quality → AI Quality**에서 **Standard** 또는 **Quality · Preview**를 선택하고 PC를 다시 시작하세요. AI가 분석하는 해상도만 바뀌며 전송 해상도는 유지됩니다. Preview는 더 많은 픽셀을 분석하지만 모든 장면의 윤곽과 입체감이 더 좋아진다고 보장하지는 않습니다.

**DAD Small**은 비교용 모델로, 기본 설치에는 포함되지 않습니다. 추가하려면 앱을 중지하고 설치 폴더에서 아래 명령을 실행하세요. 현재는 명령어로만 추가할 수 있으며 GUI 다운로드 기능은 없습니다.

```powershell
.\.venv\Scripts\python.exe -m quest3d.cli setup-model --model-id distill_any_depth_small
```

약 99 MB를 다운로드한 뒤 **Settings → Quality → Depth model**에서 선택할 수 있습니다. 설치된 모델은 영상 전송 중에도 바꿀 수 있고, 설치하지 않은 모델은 비활성화됩니다. 모델의 고정 revision, SHA-256과 라이선스는 `config/models.json`과 [제3자 고지](../THIRD_PARTY_NOTICES.md)에 기록되어 있습니다. 추론 중에는 모델을 다운로드하지 않습니다.

## 업데이트·제거

PC를 중지하고 앱을 종료한 뒤 **새 Desktop Setup EXE → 기존 설치 폴더 선택 → 업데이트** 순서로 진행합니다. Sterevi가 관리하는 파일만 갱신하며 설정, 페어링 정보, 모델과 사용자 파일은 보존합니다. 이전 앱과 가상환경(venv)은 업데이트 백업에 남습니다. 설치 검사가 실패하거나 중단된 작업을 다시 실행하면 이전 상태로 복원합니다. 업데이트가 완료된 뒤에도 설치 관리창의 **이전 버전 복원**을 사용할 수 있습니다.

Python 버전이나 호스트 파일의 해시·경로가 바뀌어 호환되지 않는 업데이트는 현재 차단합니다. 이런 경우에는 별도 설치와 데이터 이전 안내가 필요합니다. 수정된 앱 파일, 출처를 확인할 수 없는 충돌 파일, 변경된 백업과 실행 중인 앱은 덮어쓰지 않습니다. 복원 중 사용자가 직접 변경한 내용을 발견하면 보존하고 오류를 알립니다. Sterevi가 만든 것으로 확인된 바로가기만 교체하며 다른 바로가기는 유지합니다.

설치 도구는 선택한 설치 폴더 아래의 `.cache/uv`를 사용합니다. A 드라이브 등에 설치하면 처음 라이브러리를 받을 때 생기는 캐시가 C 드라이브의 기본 캐시 폴더에 쌓이는 것을 줄일 수 있습니다. 설치 검증 결과와 로그는 PC에만 저장되며 업로드하지 않습니다.

Quest APK는 같은 패키지와 서명으로 업데이트해야 기존 데이터를 유지할 수 있습니다. 서명 오류가 나면 기존 앱을 강제로 제거하지 말고 파일의 출처와 데이터 이전 안내를 확인하세요.

PC 앱을 제거하려면 **PC 중지 후 종료 → 설치 폴더의 Install-Quest3D.cmd → 제거·복구 보관** 순서로 진행합니다. Sterevi의 방화벽 규칙이 있으면 그 규칙을 정리할 때만 관리자 승인을 요청합니다. 규칙이 없는 것이 확인되면 다시 조회한 뒤 관리자 요청을 생략합니다. 승인을 취소하거나 정리가 실패하면 앱을 보존합니다. 바로가기 제거와 파일 보관은 원래 Windows 사용자의 권한으로 처리합니다.

확인된 설치 폴더는 같은 상위 폴더의 `.Quest3D-removed-<ID>`로 옮겨 보관하고, 정확히 일치하는 Sterevi 바로가기만 제거합니다. **파일을 보관하므로 디스크 공간은 확보되지 않습니다.** 설정, 모델과 페어링 정보를 남겨 복구할 수 있도록 하는 방식이며 폴더 전체를 삭제하는 기능은 아닙니다. 직접 복구하려면 보관 폴더를 원래 설치 경로로 되돌린 뒤 설치 관리창과 바로가기를 확인하세요. Python 공식 설치기가 별도로 등록한 앱 전용 Python은 Windows의 설치된 앱에서 확인해 제거할 수 있습니다. 다른 프로그램이 사용하는 Python은 보존하세요. Quest 앱을 제거하면 앱 데이터, 페어링 정보와 화면 설정도 삭제되므로 업데이트와 구분해야 합니다.

## 오류와 제한

| 증상 | 확인 |
|---|---|
| 다운로드 실패 | 인터넷 연결과 디스크 공간을 확인하고 설치 로그 확인. 같은 설치 파일로 재시도 |
| Python 준비 실패 | Python 3.12.6 x64와 Tk의 설치 상태 및 충돌 확인. 필요하면 `install.ps1 -Python <경로>`로 지정 |
| CUDA 검사 실패 | Turing sm75 지원 여부, 드라이버와 로그 확인. 다른 GPU 아키텍처나 CPU로 대체 실행 불가 |
| 앱 화면 검사 실패 | ZIP 전체를 다시 풀고 Qt/QML/리소스 오류 로그 확인. 검사를 통과하기 전에는 설치 미완료 |
| PC 검색·연결 실패 | PC 시작 상태, 같은 로컬 네트워크 연결, 연결 허용과 mDNS 확인. 게스트 Wi-Fi의 기기 간 통신 제한도 확인. 주소 직접 입력으로 검색 문제와 연결 문제 구분 |
| USB 기기 없음 | USB 데이터 케이블, 개발자 모드, ADB 드라이버와 USB 디버깅 승인 확인 |
| APK 서명 오류 | 기존 앱과 새 APK의 패키지·서명 확인. 설치기가 기존 앱을 자동으로 제거하지 않음 |
| PC 시작 실패 | 16:9 모니터, 다른 Sunshine 서버의 포트 사용 여부와 진단 확인 |
| Quest only 비활성 | Steam Streaming Speakers 설치·활성화 여부, 음량과 PC 기본 출력 장치 확인 |
| 3D 윤곽 겹침 | Depth를 낮추고 윤곽 안정화를 켜서 비교. 불편하면 2D로 전환 |

보호된 콘텐츠는 캡처가 차단되어 검은 화면으로 보일 수 있습니다. 개발 PC에서는 브라우저 하드웨어 가속을 끈 뒤 영상이 정상적으로 보인다는 사용자 확인이 있었습니다. 이 결과가 모든 서비스, 작품과 브라우저 버전을 지원하거나 DRM을 해제한다는 뜻은 아닙니다.

개발 PC에서 최근 측정한 DAD Standard / Quality의 처리 속도는 **새 3D 영상 약 38.66 / 34.64개/s**입니다. 이는 PC에서 새 결과를 만드는 속도입니다. 60회/s 반복 게시, Quest가 실제로 받는 FPS, 전체 지연과 영상·음성 동기화 결과는 각각 별도로 확인해야 합니다. 얇은 사물과 가려진 배경의 윤곽을 만드는 데도 한계가 남아 있습니다.

## 진단과 공개 전 확인

설치 로그는 설치창에서, 사용 중의 진단은 PC 앱에서 열 수 있습니다. PC 주소, 파일 경로와 장치 정보가 들어갈 수 있으므로 내용을 확인한 뒤 공유하세요. `config/artifacts`에는 개인 설정, 페어링 정보와 실행 기록이 생깁니다. **설치 폴더 전체를 업로드하거나 다른 사람에게 전달하지 마세요.**

<details>
<summary>이전 검증과 현재 배포의 구분</summary>

이전 2026-09-11 후보는 같은 PC의 새 폴더·새 venv·실제 PC 시작/중지를 확인했지만 Python 공식 설치기 자체, 새 host의 Quest 페어링·영상, 다른 물리 PC는 확인하지 않았다. 이후 DAD·Quest 3 검색·AI Quality·화면 설정·소리가 추가됐다. 이전 ZIP/검증을 최신 공개판 검증으로 재사용하지 않는다.

</details>

공개 후보를 검증할 때는 파일 무결성, 라이선스 고지와 대응 소스를 확인합니다. 이어서 **새 설치 → 바로가기 실행 → 개인 네트워크 연결 → Scan/새 PIN → 실제 양안 표시 → 설정 보존 → 정상 종료·소리 복원 → 업데이트/제거** 흐름을 확인하고 결과를 `release-validation.json`에 남깁니다. 빌드 방법과 아직 재현하지 못한 조건은 [BUILDING](BUILDING.md)을 확인하세요.
